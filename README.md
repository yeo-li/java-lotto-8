# java-lotto-precourse

## 1. 입력

### ✅ 구입 금액 입력 기능

- 로또 구매 금액을 입력 받는다.

```text
구입금액을 입력해 주세요.
8000
```

---

### ✅ 당첨 번호 입력 기능

```text
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```

---

### ✅ 보너스 번호 입력 기능

```text
보너스 번호를 입력해 주세요.
7
```

---

## 2. 출력

### ☑️ 발행 로또 수량 및 번호 출력 기능

```text
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```

---

```text

3개 일치 (5,000원) - 1개

5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

---

### ☑️ 수익률 출력 기능


---

### ☑️ 예외 상황 시 에러 문구 출력 기능

```text

```

## 3. 핵심 기능

### ✅ 로또 구입 금액 저장 기능

- 사용자 입력값의 공백을 제거한다.
- 사용자가 입력한 로또 금액을 저장한다.
- 구입 금액은 1,000원 단위로 입력 받는다.

### ⚠️ 기능 예외 상황

- 입력값에 숫자를 제외한 다른 값이 있는 경우
- 입력값이 `int` 자료형의 범위를 초과하는 경우
- 입력값이 1,000원 단위로 나누어 떨어지지 않는 경우
- 입력값이 0원인 경우
- 입력값이 공백인 경우

---

### ✅ 당첨 번호 저장 기능

- 사용자가 입력한 당첨 번호를 오름차순으로 정렬하여 저장한다.
- 입력의 공백은 모두 제거 한다.

### ⚠️ 기능 예외 상황

- 숫자, 컴마(,) 외 다른 문자가 포함되어 있는 경우
- 당첨 번호의 갯수가 6개가 아닌 경우
- 당첨 번호에 공백만 입력된 경우
- 당첨 번호에 공백이 포함되어 있는 경우
- 당첨 번호가 1 미만, 45 초과인 경우
- 당첨 번호의 숫자가 중복되는 경우

---

### ✅ 보너스 번호 저장 기능

- 사용자가 입력한 보너스 번호를 저장한다.
- 입력의 공백은 모두 제거 한다.

### ⚠️ 기능 예외 상황

- 숫자 외 다른 문자가 포함되어 있는 경우
- 보너스 번호가 1 미만, 45 초과인 경우
- 당첨 번호와 중복되는 경우

---

### ✅ 로또 발행 기능

- 로또 번호 6개를 무작위로 추출한 뒤 저장한다.
- 로또 번호는 중복되지 않는다.
- 로또 번호는 오름차순으로 정렬되어야 한다.
- 입력된 금액만큼 로또를 발행한다.

### ⚠️ 기능 예외 상황

- 로또 발행 기능의 예외 상황은 없습니다.

---

### ✅ 로또 통계 계산 기능

- 발행된 로또를 당첨 번호, 보너스 번호와 비교하여 당첨 통계를 낸다.

### ⚠️ 기능 예외 상황

- 로또 통계 계산 기능의 예외 상황은 없습니다.

--- 

### 🏁 수익률 계산 기능

- 당첨 통계와 구입 금액을 이용해 총 수익률을 계산한다.
- 당첨 통계는 정수가 아닌 실수로 저장한다.

### ⚠️ 기능 예외 상황

- 수익률 계산 기능의 예외 상황은 없습니다.
